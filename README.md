# Домашнее задание к работе 8

## Условие задачи
Вычислить с использованием цикла `for` значение ряда для заданных пользователем значений `a` и `n`.

## 1. Алгоритм и блок-схема

### Алгоритм
1. **Начало**
2. Задать исходные данные (ввод с клавиатуры):
   - `a` — вещественное число.
   - `n` — целое число (количество слагаемых/предел).
3. Инициализировать переменные для суммы (`sum = 0.0`) и текущего слагаемого (`term = 1.0`).
4. Организовать цикл `for` от `i = 0` до `n`:
   - На первой итерации (`i == 0`) вычислить первое слагаемое: `term = 1.0 / a`.
   - На последующих итерациях вычислять текущее слагаемое последовательно: `term = term / (a + i)`.
   - Добавить полученное слагаемое к общей сумме: `sum += term`.
5. Вывести итоговое значение суммы ряда.
6. **Конец**

## 2. Реализация программы

```c
#include <stdio.h>

int main() {
    double a;
    int n;

    printf("Введите a: ");
    scanf("%lf", &a);
    printf("Введите n: ");
    scanf("%d", &n);

    double sum = 0.0;
    double term = 1.0;

    for (int i = 0; i <= n; i++) {
        if (i == 0) {
            term = 1.0 / a;
        } else {
            term = term / (a + i);
        }
        sum += term;
    }

    printf("Результат = %lf\n", sum);

    return 0;
}
```
